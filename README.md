# To-Do List Web Application

## Milestone 1 – Interactive Frontend Web Application

### Project Overview
Our project is a browser-based To-Do List application designed to help users organize, manage, and track their daily tasks. The application is intended for students, teachers, employees, business professionals, and anyone who wants to stay organized and productive.

For Milestone 1, the project focuses on developing an Interactive Frontend Web Application using HTML, CSS, and JavaScript.

---

### Milestone 1 – Scope
The frontend application provides a simple, clean, and user-friendly interface for managing tasks.

---

### Current Features
- Welcome section with user name
- Search tasks
- Add new tasks
- Edit tasks
- Delete tasks
- Task categories
- Task priorities
- Due dates
- Completed and pending tasks
- Task filtering
- Overall progress bar
- Task summary
- Overdue task indicator
- Notification area
- User profile
- Sidebar navigation
- Responsive layout

---

### Frontend Technologies
- **HTML** — Defines the structure and content of the application.
- **CSS** — Controls the layout, design, colors, spacing, and appearance.
- **JavaScript** — Provides interactive functionality and dynamic task management.
